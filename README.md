# Student Grade Calculator

A simple Python program that evaluates a numeric score entered by the user and assigns a letter grade based on predefined criteria.

---

## Grading Criteria

| Score Range | Grade |
| :--- | :--- |
| **90 – 100** | A |
| **80 – 89.9** | B |
| **70 – 79.9** | C |
| **60 – 69.9** | D |
| **0 – 59.9** | E |
| **< 0 or > 100** | Invalid mark |
